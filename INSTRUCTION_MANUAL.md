# Game Instruction Manual — Safe Internet: Cyber Guardian

## Starting the game
1. Extract `Safe-Internet.zip`.
2. Open `index.html` in a modern desktop browser, or serve the folder with VS Code Live Server.
3. Select **Start Adventure**. Select **How to Play** first if you want to review the controls.

## Controls
| Key | Action |
|---|---|
| A / D or Left / Right | Move left or right |
| W / Up Arrow / Space | Jump |
| E | Open the nearby mission terminal |
| Mouse | Select an answer and use menu buttons |

## How to complete a mission
1. Move the character close to a glowing terminal.
2. Press E when the interaction prompt appears.
3. Read the scenario and select the safest answer.
4. Correct answers complete the mission and add 100 points. If an answer is incorrect, read the feedback and try again.
5. Complete all five terminals to secure the network.

## Sound
Use the **Sound On/Off** button in the game toolbar to control sound effects. Some browsers activate audio only after the first user interaction.
